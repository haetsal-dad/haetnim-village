# 햇님 마을 게임

가족이 함께 즐기는 작은 브라우저 게임 두 가지입니다. 설치도, 인터넷 연결도 필요 없이 파일 하나로 실행됩니다.

- **햇님 마을 주사위 여행** — `dice.html`
- **햇님 마을 사다리 게임** — `ladder.html`

바로 하기: https://haetsal-dad.github.io/haetnim-village/

공식 배포처: 블로그 '10월의 햇살' (https://blog.naver.com/graydrama) 과 이 저장소

## 만든 사람

| 역할 | 맡은 일 |
| --- | --- |
| 기획·감수: 햇살이 아빠 | 게임 구상, 규칙, 캐릭터와 관계 설정, 대사 원칙, 그림 고르기, 결과물 확인과 고칠 점 지시 |
| 코드·글: Claude (Anthropic) | 프로그램 작성, 대사와 안내문 작성 |
| 그림: ChatGPT (OpenAI) | 게임에 쓰인 그림. 단추 같은 간단한 그림 몇 개는 Claude가 그렸습니다 |

## 원본 확인

공식 배포처가 아닌 곳에서 받은 파일은 바뀌었을 수 있습니다. 받은 파일의 SHA-256 값이 `SHA256SUMS.txt`와 같은지 확인하세요.

- Windows: 명령 프롬프트에서 `certutil -hashfile 파일이름 SHA256`
- Mac/Linux: 터미널에서 `shasum -a 256 파일이름`
